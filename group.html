One practice, five disciplines. One chain when a client wants it.

For clients running more than one workstream with us. If you came for a single discipline, go straight to it.

Philosophy

One instinct runs through all five disciplines: work that comes from where it is made. Dar es Salaam's materials, light and daily life shape the architecture, the products, the shop and the code alike, built to a standard that travels anywhere.

How they relate

Each discipline takes its own clients, and most never overlap. When a client does want more than one stage (architecture, then furniture, then textiles), the referral is internal and one team can answer for the whole thing.

That option exists. It is never imposed.
